# WilchDev (wilch.dev portfolio)

Kelvin Wilch's portfolio. Web only, Next.js 15 App Router, static export, Vercel.

- **Brand:** one palette. Primary `#4F3FD9` (indigo), accent `#D4F26A` (lime).
  Light + **true-black** dark (`#000` canvas, `#0E0E10` / `#1A1A1D` raised).
- **Colour source of truth:** `src/theme/colors.ts` (inlined as CSS variables).
  Never write a hex in a component. Every text pair is AA-checked by
  `src/theme/contrast.test.ts` (`npm run contrast` prints the report); add a
  row to `contrast-pairs.ts` for any new pairing.
- **Design:** keeps its own look (Material 3 Expressive, from Ro5n3R), not
  ClassPing (`design_role: own`). Source: `design/claude-design/project/Main.dc.html`.
  Departures from it (decided 2026-11-26): true-black dark, liquid glass on
  floating chrome only (nav, menu sheet, hero name tag and pause button),
  Barlow Condensed instead of Roboto Flex, single palette.
- **Fonts:** Barlow Condensed (all weights + italics, `preload: false`) and
  Google Sans Code for mono, both via `next/font/google` in `src/theme/fonts.ts`.
- **Copy:** all text lives in `src/content/`. `docs/COPY.md` tracks wording changes.
  `src/content/skills4u.samples.ts` is generated by `node scripts/sync-skills.mjs`.
- **Motion:** loops only run with OS motion allowed AND the on-page pause off.
  Entrances use `backwards` fill. Glyphs over spinning shapes need `relative`.
- **Checks:** `npm run lint && npm run typecheck && npm test && npm run build`,
  then `npm run test:e2e`. Screenshots: `node scripts/screenshots.mjs <dir>`.
- **Plan:** `docs/PLAN.md`. Build phase by phase, one branch per phase.
- **Never** commit to or push `main` without asking: a push there is a release.
